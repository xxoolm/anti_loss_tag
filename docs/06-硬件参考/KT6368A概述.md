## 一、芯片简介

### 1.1 产品定位

KT6368A 是一款**双模蓝牙数据芯片**，支持经典蓝牙和BLE双模，主要用于数据透传和AT指令控制。

**主要特点**：
- ✅ 支持 Bluetooth 5.1
- ✅ SOP-8 超小封装
- ✅ 超低功耗（20µA）
- ✅ 支持UART透传
- ✅ 支持AT指令配置
- ✅ 内置晶体振荡器

### 1.2 应用场景

**防丢标签**：
- 物品防丢（钥匙、钱包、宠物等）
- 儿童防走失
- 老人监护

**其他应用**：
- 数据透传模块
- 远程控制
- 传感器数据采集
- 智能家居控制

## 三、引脚定义

### 3.1 引脚图

```
        ┌─────────┐
 VCC ──┤1      8├── GND
 TX  ──┤2      7├── IO1
 RX  ──┤3      6├── IO2
 IO3 ──┤4      5├── IO4
        └─────────┘
      KT6368A (SOP-8)
```

### 3.2 引脚功能表

| 引脚 | 名称  | 类型   | 功能描述                          |
| ---- | ----- | ------ | --------------------------------- |
| 1    | VCC   | 电源   | 供电正极（2.2V-3.6V，推荐3.3V）   |
| 2    | TX    | 输出   | UART发送端（连接MCU的RX）          |
| 3    | RX    | 输入   | UART接收端（连接MCU的TX）          |
| 4    | IO3   | I/O    | 通用IO3（可配置为ADC/GPIO）        |
| 5    | IO4   | I/O    | 通用IO4（可配置为ADC/GPIO）        |
| 6    | IO2   | I/O    | 通用IO2（可配置为按键输入）         |
| 7    | IO1   | I/O    | 通用IO1（可配置为LED控制）         |
| 8    | GND   | 地     | 供电负极（地线）                   |

### 3.3 引脚功能详解

#### VCC（引脚1）
- **功能**：主电源输入
- **电压范围**：2.2V - 3.6V
- **推荐电压**：3.3V
- **电流要求**：至少能提供40mA（启动瞬态）
- **去耦电容**：建议在VCC和GND之间并联100nF陶瓷电容

#### TX（引脚2）
- **功能**：UART数据发送
- **电平**：3.3V CMOS
- **波特率**：默认9600bps（可通过AT指令修改）
- **连接**：连接到MCU的RX引脚

#### RX（引脚3）
- **功能**：UART数据接收
- **电平**：3.3V CMOS
- **波特率**：默认9600bps（可通过AT指令修改）
- **连接**：连接到MCU的TX引脚

#### IO1-IO4（引脚4-7）
- **功能**：通用I/O引脚
- **可配置**：通过AT指令配置为：
  - GPIO输入/输出
  - ADC输入
  - PWM输出
  - 按键输入
  - LED控制

#### GND（引脚8）
- **功能**：电源地
- **连接**：连接到系统地线

## 五、内部模块

### 5.1 蓝牙控制器

**BLE 5.1控制器**：
- 支持 BLE 5.1 所有特性
- 支持 1Mbps/2Mbps PHY
- 支持扩展广播
- 支持多定向

**经典蓝牙控制器**：
- 支持蓝牙经典 2.1+EDR
- 支持 SPP（串口协议）
- 支持 HFP/A2DP（可选）

### 5.2 串口接口

**UART参数**：
- 波特率：9600（默认）、19200、38400、57600、115200
- 数据位：8位
- 停止位：1位
- 校验位：无
- 流控：无

**透传模式**：
- 串口数据 ↔ BLE数据 自动转换
- 无需额外协议处理

### 5.3 GPIO控制器

**功能**：
- 4个通用I/O引脚
- 可配置为输入/输出
- 支持ADC采样（10bit，0-3.3V）
- 支持PWM输出
- 支持外部中断

## 六、工作模式

### 6.1 模式列表

| 模式       | 电流 | 进入条件         | 退出条件         | 说明            |
| ---------- | ---- | ---------------- | ---------------- | --------------- |
| **关断态** | 1µA  | 上电或AT指令     | 复位或中断       | 最小功耗        |
| **睡眠态** | 20µA | 空闲超时         | 串口活动或定时器 | 低功耗待机      |
| **广播态** | 4mA  | AT指令或配置     | 连接建立         | BLE广播         |
| **连接态** | 4mA  | BLE连接建立      | 连接断开         | BLE连接活跃     |
| **透传态** | 4mA  | 串口有数据       | 串口空闲超时     | 数据透传        |

### 6.2 模式切换

```
上电
  ↓
广播态（默认，120秒）
  ↓ 连接成功
连接态
  ↓ 串口活动
透传态
  ↓ 空闲超时（默认10秒）
睡眠态
  ↓ 串口活动/定时器
透传态
```

**内部RC振荡器**：

## 十一、应用建议

### 11.1 电源设计

**推荐方案**：
```
3.3V稳压源
  │
  ├─ 100µF电解电容（滤波）
  │
  ├─ 100nF陶瓷电容（去耦，靠近芯片）
  │
  └─ KT6368A VCC
```

**注意事项**：
- ⚠️ 电源纹波 < 100mV
- ⚠️ 瞬态电流能力 > 40mA
- ⚠️ 不要直接用5V供电（会损坏芯片）

### 11.2 天线设计

**板载天线**：
- PCB天线（推荐倒F型）
- 50Ω阻抗匹配
- 避开金属物体

**外接天线**：
- IPEX接口
- 2.4GHz陶瓷天线
- 增益：2-3dBi

### 11.3 布局建议

**关键点**：
1. 天线远离金属物体
2. 去耦电容靠近芯片
3. 串口线短且直
4. 地线完整（地平面）
5. 避免过孔和折角
