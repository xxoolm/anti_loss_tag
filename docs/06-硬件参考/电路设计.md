## 二、电源电路设计

### 2.1 电池供电方案

#### 方案A：锂电池供电（推荐）

**电路图**：
```
    ┌──────────┐     ┌──────────┐
    │  锂电池   │     │  TP4056  │
    │ 3.7V     │────▶│ 充电管理  │
    │ 500mAh   │     │          │
    └──────────┘     └────┬─────┘
                           │ VCC
                           │ 3.7-4.2V
                           ▼
                    ┌──────────────┐
                    │   XC6206     │
                    │   3.3V LDO   │
                    └──────┬───────┘
                           │ 3.3V
                           ├─ 100µF
                           │
                           ▼
                      ┌─────────┐
                      │ KT6368A │
                      └─────────┘
```

**器件清单**：
| 器件   | 型号        | 数量 | 说明           |
| ------ | ----------- | ---- | -------------- |
| 电池   | 402030锂电池 | 1    | 3.7V 500mAh    |
| 充电IC | TP4056      | 1    | 锂电池充电管理 |
| 稳压IC | XC6206P332  | 1    | 3.3V LDO       |
| 电容   | 100µF/6.3V  | 1    | 电解电容       |
| 电容   | 100nF/50V   | 1    | 陶瓷电容       |

**参数计算**：

**续航时间**（500mAh电池）：
```
连接态电流：4mA
待机态电流：20µA

纯连接续航：500mAh ÷ 4mA = 125小时 ≈ 5天
纯待机续航：500mAh ÷ 0.02mA = 25000小时 ≈ 1041天
混合续航（假设50%连接）：约2-3天
```

**充电电流**：
```
TP4056充电电流 = 1000/R_prog (kΩ)
R_prog = 2kΩ → 500mA充电（约1小时充满）
```

#### 方案B：纽扣电池供电

**电路图**：
```
    ┌──────────┐     ┌──────────┐
    │ CR2032   │     │  去耦    │
    │ 3V纽扣   │────▶│ 100nF    │────▶ 3V (直接供电)
    └──────────┘     └──────────┘
```

**优点**：
- ✅ 电路简单，无需稳压
- ✅ 成本低
- ✅ 体积小

**缺点**：
- ❌ 容量小（220mAh）
- ❌ 续航短
- ❌ 不可充电

**适用场景**：
- 一次性设备
- 低功耗应用
- 成本敏感产品

### 3.2 晶体电路

**外部晶振（推荐）**：
```
           ┌──────────────────┐
           │     KT6368A       │
    24MHz  │                  │
   ┌┴┐     │              XT │
   │ │     │              IN │
   └┬┘     │                  │
  12pF     │              XT │
    │     │              OUT │
    │     └──────────────────┘
    │            │
  12pF         12pF
    │            │
   GND         GND
```

**负载电容计算**：
```
CL = (C1 * C2) / (C1 + C2) + C_stray

其中：
- C1, C2 = 12pF（实际值需调试）
- C_stray = 2-5pF（PCB寄生电容）
- CL = 8-12pF（晶振规格书要求）

推荐：C1 = C2 = 12pF ±5%
```

## 四、外设电路设计

### 4.1 LED指示电路

**连接方式**（IO1）：
```
3.3V ────┬───────┐
         │       │
         │     ┌─┴─┐
330Ω     │  ┌─┴┐ │
    ┌────┴──┤LED ├──┴────▶ IO1
    │       └───┘
    │
   GND
```

**参数计算**：
```
LED压降：Vf = 2.0V (红色)
电流限制：If = 10mA
限流电阻：R = (3.3V - Vf) / If
         = (3.3V - 2.0V) / 0.01A
         = 130Ω

推荐：330Ω（更亮但不刺眼）
```

**闪烁模式**：
- 快闪（1Hz）：连接中
- 慢闪（0.2Hz）：广播中
- 常亮：已连接
- 熄灭：睡眠/关断

---

### 4.2 按键输入电路

**连接方式**（IO2）：
```
3.3V ────┬───────── IO2
         │
        10kΩ
         │
   ┌─────┴─────┐
   │  轻触开关  │
   └─────┬─────┘
         │
        GND
```

**按键检测**：
- **未按下**：IO2 = 高电平（3.3V）
- **按下**：IO2 = 低电平（0V）
- **上拉电阻**：10kΩ（内部或外部）

**去抖动**：
```c
// 软件去抖（示例）
if (button_pressed) {
    delay_ms(20);  // 等待20ms
    if (button_pressed) {  // 再次确认
        // 有效按键
    }
}
```

---

### 4.3 蜂鸣器驱动电路

**有源蜂鸣器（推荐）**：
```
IO3 ──────┬─────────┬─────┬────── 蜂鸣器(+)
          │       │     │
        1kΩ     NPN   │
          │    2N3904  │
          │    ▼       │
   ┌──────┴─┤ E     ┌──┴──┐
   │        │ C     │     │
   │     ┌──┤ B     │ 10µF│
   │     │  │       │     │
  GND    GND GND     GND   GND
```

**参数计算**：
```
蜂鸣器电流：I_buzzer = 20mA
NPN β值：β = 100
基极电流：I_b = I_buzzer / β = 0.2mA
基极电阻：R_b = (3.3V - 0.7V) / 0.2mA = 13kΩ

推荐：1kΩ（确保深度饱和）
```

---

### 4.4 马达驱动电路

**振动马达**：
```
IO4 ──────┬─────────┬────── 马达(+)
          │       │      │
        100Ω    NPN     │
          │   2N3904    │
          │    ▼        │
   ┌──────┴─┤ E     ┌───┴────┐
   │        │ C     │  1N4148 │
   │     ┌──┤ B     │   二极管│
   │     │  │       │(续流)   │
  GND    GND GND     GND      GND
```

**注意事项**：
- ✅ 二极管必须反向并联（续流）
- ✅ 二极管选型：1N4148或肖特基
- ✅ 马达工作电压：3.0V（直接接3.3V）

## 五、天线设计

### 5.1 PCB天线（推荐）

**倒F型天线**：
```
      ┌────────┐
      │  GND   │
      │        │
      │  辐射部│
      │  24mm  │
      │        │
      └────────┘
          │
         馈点
```

**设计参数**：
- 频率：2.4GHz
- 带宽：100MHz
- 增益：2dBi
- 阻抗：50Ω
- 尺寸：24mm × 10mm

**PCB层叠**：
```
Top Layer     ─── 天线
Dielectric    ─── FR4 (h=1.6mm, εr=4.4)
Bottom Layer  ─── 完整地平面
```

**注意事项**：
- ⚠️ 天线正下方不能走线
- ⚠️ 天线周围5mm内无金属
- ⚠️ 地平面要完整
- ⚠️ 板材用FR4或Rogers

---

### 5.2 IPEX接口（可选）

**焊接型IPEX**：
```
   ┌─────────┐
   │ IPEX   1│──── 天线(50Ω同轴线)
   │   2    │
   │   3    │──── RF
   │   4    │──── GND
   └─────────┘
```

**引脚定义**：
1. NC（不接）
2. Shield（地）
3. RF（信号）
4. Shield（地）

**同轴线规格**：
- 型号：1.13mm同轴线
- 特性阻抗：50Ω
- 长度：< 100mm

       │      │
    TVS   3.3V稳压
    二极    管
      │

```

**TVS选型**：
- 型号：SMBJ5.0A
- 击穿电压：5.0V
- 最大钳位电压：7.5V

### 6.2 ESD保护

**ESD保护二极管**：
```
IO ────┬────── IO
       │
     ESD
    二极管
       │
      GND
```

**推荐型号**：
- SRV05-4（4路ESD保护）

         │
        GND
```

**选型**：
- 型号：SMD1812P050SA
- 保持电流：500mA
- 触发电流：1000mA

## 七、PCB布局建议

### 7.1 元件布局原则

1. **电源部分**：靠近电源接口
2. **去耦电容**：紧邻芯片VCC引脚
3. **天线区域**：PCB边缘，远离金属
4. **按键/LED**：便于操作和观察
5. **测试点**：关键信号引出

### 7.2 走线规则

**电源线**：
- VCC/GND：≥0.3mm
- 电流路径短且直

**信号线**：
- 串口线：0.15mm
- GPIO线：0.15mm
- 避免长距离走线

**射频线**：
- 天线馈线：50Ω阻抗控制
- 长度：< 30mm

## 十、测试验证

- BLE广播正常
- 可被手机/HA扫描
- 连接建立稳定

**外设测试**：
- 按键响应
