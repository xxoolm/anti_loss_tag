# 开发环境搭建

> **Home Assistant BLE 防丢标签集成开发环境配置**
> 
**目标读者**：开发者  
**难度等级**：⭐⭐ 简单

## 一、环境要求

### 1.1 硬件要求

- **CPU**：双核及以上
- **内存**：4GB及以上
- **磁盘**：10GB可用空间
- **蓝牙适配器**：
  - 内置蓝牙4.0+
  - USB蓝牙适配器（推荐蓝牙5.0）
  - ESP32蓝牙代理（可选）

### 1.2 软件要求

| 组件              | 版本要求 | 说明                      |
| ----------------- | -------- | ------------------------- |
| **Python**        | 3.11+    | HA运行环境               |
| **Home Assistant**| 2024.1+  | HA版本                   |
| **Git**           | 最新     | 版本控制                 |
| **VS Code**       | 最新     | 推荐IDE                   |
| ** bleak**        | >=0.21.0 | BLE库                    |
| ** bleak-retry-connector** | >=3.0.0 | 重试连接器 |

## 二、本地开发环境搭建

### 2.1 获取源代码

**克隆仓库**：
```bash
# HTTPS方式
git clone https://github.com/xxoolm/anti_loss_tag.git

# SSH方式（如果已配置SSH密钥）
git clone git@github.com:xxoolm/anti_loss_tag.git

# 进入项目目录
cd anti_loss_tag
```

**检查分支**：
```bash
# 查看所有分支
git branch -a

# 切换到开发分支
git checkout develop

# 或创建新分支
git checkout -b feature/your-feature
```

---

### 2.2 安装依赖

**安装运行时依赖**：
```bash
# 创建虚拟环境（推荐）
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# 或 venv\Scripts\activate  # Windows

# 安装依赖
pip install -r requirements.txt
```

**requirements.txt内容**：
```txt
bleak>=0.21.0
bleak-retry-connector>=3.0.0
```

**安装开发依赖**（可选）：
```bash
pip install -r requirements-test.txt
```

**requirements-test.txt内容**：
```txt
pytest>=7.0.0
pytest-asyncio>=0.21.0
pytest-cov>=4.0.0
ruff>=0.1.0
mypy>=1.0.0
```

---

### 2.3 安装到Home Assistant

**方法1：符号链接（推荐用于开发）**
```bash
# 进入HA配置目录
cd ~/.homeassistant

# 创建custom_components目录（如果不存在）
mkdir -p custom_components

# 创建符号链接
ln -s /path/to/anti_loss_tag/custom_components/anti_loss_tag \
      custom_components/anti_loss_tag

# 验证
ls -l custom_components/anti_loss_tag/
```

**方法2：直接复制（用于测试）**
```bash
# 复制文件
cp -r /path/to/anti_loss_tag/custom_components/anti_loss_tag \
      ~/.homeassistant/custom_components/

# 验证
ls ~/.homeassistant/custom_components/anti_loss_tag/
```

**方法3：HACS开发模式（推荐）**
```bash
# 在HACS中添加自定义仓库
# 仓库类型：Integration
# URL：/path/to/local/repo
```

---

### 2.4 配置Home Assistant

**启用调试日志**：
```yaml
# configuration.yaml
logger:
  default: info
  logs:
    custom_components.anti_loss_tag: debug
    bleak: debug
    bleak.exc: debug
    bluetooth_adapters: debug
```

**重启Home Assistant**：
```bash
# HA OS
hassio host restart

# Docker
docker restart home-assistant

# Python venv
# 停止HA，然后重新启动
```

## 四、代码检查工具

### 4.1 Ruff（代码检查和格式化）

**安装**：
```bash
pip install ruff
```

**使用**：
```bash
# 检查代码
ruff check custom_components/anti_loss_tag/

# 自动修复
ruff check --fix custom_components/anti_loss_tag/

# 格式化代码
ruff format custom_components/anti_loss_tag/
```

**配置文件**（pyproject.toml）：
```toml
[tool.ruff]
line-length = 88
target-version = "py311"

[tool.ruff.lint]
select = ["E", "F", "W", "I", "N", "UP", "B", "C4"]
ignore = ["E501", "B008"]

[tool.ruff.lint.per-file-ignores]
"__init__.py" = ["F401"]
```

---

### 4.2 MyPy（类型检查）

**安装**：
```bash
pip install mypy
```

**使用**：
```bash
# 类型检查
mypy custom_components/anti_loss_tag/

# 严格模式
mypy --strict custom_components/anti_loss_tag/
```

**配置文件**（setup.cfg）：
```ini
[mypy]
```

## 五、测试环境

### 5.1 Pytest配置

**安装**：
```bash
pip install pytest pytest-asyncio pytest-cov
```

**运行测试**：
```bash
# 运行所有测试
pytest tests/

# 运行单个测试文件
pytest tests/test_validation.py

# 带覆盖率报告
pytest tests/ --cov=custom_components/anti_loss_tag --cov-report=html

# 详细输出
pytest tests/ -v
```

**pytest.ini配置**：
```ini
[pytest]
testpaths = tests
python_files = test_*.py
python_classes = Test*
python_functions = test_*
asyncio_mode = auto
```

## 六、开发工作流

### 6.1 分支策略

```
main (生产)
  ↑
  ├─ develop (开发)
  │    ↑
  │    ├─ feature/* (功能分支)
  │    ├─ bugfix/* (修复分支)
  │    └─ hotfix/* (紧急修复)
```

**分支命名规范**：
- `feature/功能名称`
- `bugfix/问题描述`
- `hotfix/紧急修复`

---

### 6.2 开发流程

**1. 创建功能分支**：
```bash
git checkout develop
git pull origin develop
git checkout -b feature/add-new-feature
```

**2. 开发和测试**：
```bash
# 编辑代码
# 运行测试
pytest tests/
# 代码检查
ruff check custom_components/anti_loss_tag/
```

**3. 提交代码**：
```bash
git add .
git commit -m "feat: 添加新功能"
```

**4. 推送和PR**：
```bash
git push origin feature/add-new-feature
# 在GitHub上创建Pull Request
```

---

### 6.3 Commit规范

**Conventional Commits**：
```
<type>(<scope>): <subject>

<body>

<footer>
```

**类型（type）**：
- `feat`：新功能
- `fix`：Bug修复
- `docs`：文档更新
- `style`：代码格式
- `refactor`：重构
- `test`：测试
- `chore`：构建/工具

**示例**：
```bash
# 新功能
git commit -m "feat(device): 添加电量读取功能"

# Bug修复
git commit -m "fix(connection): 修复重连失败问题"

# 文档更新
git commit -m "docs(readme): 更新安装说明"
```

## 七、常见问题

### Q1: 导入错误

**错误**：
```
ImportError: No module named 'bleak'
```

**解决**：
```bash
# 确认虚拟环境已激活
which python

# 重新安装依赖
pip install -r requirements.txt
```

---

### Q2: 集成未加载

**症状**：
- HA中看不到集成
- 日志中有导入错误

**解决**：
```bash
# 检查文件位置
ls ~/.homeassistant/custom_components/anti_loss_tag/

# 检查manifest.json
cat ~/.homeassistant/custom_components/anti_loss_tag/manifest.json

# 重启HA
hassio host restart
```

---

### Q3: 测试失败

**错误**：
```
FAILED tests/test_validation.py::test_valid_ble_address
```

**解决**：
```bash
# 运行单个测试查看详情
pytest tests/test_validation.py::test_valid_ble_address -v

# 启用调试
pytest tests/test_validation.py -v -s
```
