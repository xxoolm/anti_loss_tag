## 一、文件结构

### 1.1 导入顺序

**必须顺序**：
```python
from __future__ import annotations

# 1. 标准库导入
import asyncio
import logging
from collections.abc import Callable
from dataclasses import dataclass
from datetime import datetime

# 2. 第三方库导入
import voluptuous as vol
from homeassistant.config_entries import ConfigEntry
from homeassistant.core import HomeAssistant
from bleak import BleakClient
from bleak.exc import BleakError

# 3. 本地模块导入（使用相对导入）
from . import const
from .device import BLEDevice
from .sensor import BatterySensor
```

**禁止**：
```python
# ❌ 错误：顺序混乱
from bleak import BleakClient
import asyncio
from . import const
```

---

### 1.2 模块文档字符串

**每个文件必须包含模块文档字符串**：
```python
"""KT6368A BLE 防丢标签集成。

此模块提供完整的BLE防丢标签集成，包括：
- 设备扫描和连接
- 电量和RSSI监控
- 按钮事件处理
- 报警功能
"""
```

## 二、命名约定

### 2.1 类名

**规则**：PascalCase（帕斯卡命名法）

```python
# ✅ 正确
class AntiLossTagDevice:
    pass

class OptionsFlowHandler:
    pass

# ❌ 错误
class anti_loss_tag_device:
    pass

class anti_loss_tag_device_handler:
    pass
```

---

### 2.2 函数和方法名

**规则**：snake_case（蛇形命名法）

```python
# ✅ 正确
def async_setup_entry(hass: HomeAssistant, entry: ConfigEntry):
    pass

async def _async_write_bytes(data: bytes):
    pass

# ❌ 错误
def AsyncSetupEntry(hass, entry):
    pass

async def _AsyncWriteBytes(data):
    pass
```

---

### 2.3 私有成员

**规则**：_前缀

```python
# ✅ 正确
class BLEDevice:
    def __init__(self):
        self._client = None  # 私有属性
        self._connected = False
        self._battery = 100
        
    async def _async_read(self):
        pass  # 私有方法

# ❌ 错误
class BLEDevice:
    def __init__(self):
        self.client = None  # 应该是私有
        self.__connected = False  # 不要使用双下划线
```

---

### 2.4 常量

**规则**：UPPER_SNAKE_CASE

```python
# ✅ 正确
DOMAIN = "anti_loss_tag"
UUID_NOTIFY_FFE1 = "0000ffe1-0000-1000-8000-00805f9b34fb"
UUID_BATTERY_LEVEL_2A19 = "00002a19-0000-1000-8000-00805f9b34fb"
DEFAULT_POLL_INTERVAL = 360

# ❌ 错误
domain = "anti_loss_tag"
uuid_notify_ffe1 = "0000ffe1-0000-1000-8000-00805f9b34fb"
```

## 三、类型注解

### 3.1 函数返回类型

**所有函数必须有返回类型注解**：
```python
# ✅ 正确
async def read_battery(client: BleakClient) -> int:
    """读取设备电量。"""
    data = await client.read_gatt_char(UUID_BATTERY)
    return data[0]

def is_connected() -> bool:
    """检查设备是否已连接。"""
    return self._connected

# ❌ 错误：缺少返回类型
async def read_battery(client: BleakClient):
    """读取设备电量。"""
    data = await client.read_gatt_char(UUID_BATTERY)
    return data[0]
```

---

### 3.2 可选类型

**使用 PEP 604 语法**（Python 3.10+）：
```python
# ✅ 正确：使用 | 语法
def parse_data(data: bytes | None) -> dict:
    """解析数据。"""
    if data is None:
        return {}
    return {"data": data}

# ❌ 错误：使用 Optional（过时）
from typing import Optional

def parse_data(data: Optional[bytes]) -> dict:
    """解析数据。"""
    if data is None:
        return {}
    return {"data": data}
```

---

### 3.3 集合类型

**使用内置泛型**（Python 3.9+）：
```python
# ✅ 正确：使用内置泛型
def get_devices() -> list[str]:
    """获取设备列表。"""
    return ["device1", "device2"]

def get_device_map() -> dict[str, BLEDevice]:
    """获取设备映射。"""
    return {"AA:BB:CC:DD:EE:FF": device}

def get_callbacks() -> set[Callable[[], None]]:
    """获取回调集合。"""
    return {callback1, callback2}

# ❌ 错误：使用 typing 模块（过时）
from typing import List, Dict, Set

def get_devices() -> List[str]:
    """获取设备列表。"""
    return ["device1", "device2"]
```

---

### 3.4 属性类型

**类属性也需要类型注解**：
```python
# ✅ 正确
class BLEDevice:
    def __init__(self):
        self._client: BleakClient | None = None
        self._connected: bool = False
        self._battery: int = 100
        self._last_error: str | None = None

# ❌ 错误：缺少类型
class BLEDevice:
    def __init__(self):
        self._client = None
        self._connected = False
```

## 四、异步编程

### 4.1 异步函数

**Home Assistant集成方法必须是async**：
```python
# ✅ 正确
async def async_setup_entry(hass: HomeAssistant, entry: ConfigEntry) -> bool:
    """设置集成。"""
    return True

async def async_unload_entry(hass: HomeAssistant, entry: ConfigEntry) -> bool:
    """卸载集成。"""
    return True

# ❌ 错误：同步函数
def setup_entry(hass: HomeAssistant, entry: ConfigEntry) -> bool:
    """设置集成。"""
    return True
```

---

### 4.2 回调函数

**回调使用 @callback 装饰器**：
```python
from homeassistant.core import callback

# ✅ 正确
@callback
def _async_update_state(self):
    """更新状态（非异步）。"""
    self._state = "connected"

# ❌ 错误：使用了 async
@callback
async def _async_update_state(self):
    """更新状态（非异步）。"""
    self._state = "connected"
```

---

### 4.3 锁的使用

**使用 async with 保护共享状态**：
```python
# ✅ 正确
async def _async_write_data(self, data: bytes):
    """写入数据（线程安全）。"""
    async with self._gatt_lock:
        await self._client.write_gatt_char(self._char_uuid, data)

# ❌ 错误：没有锁保护
async def _async_write_data(self, data: bytes):
    """写入数据（非线程安全）。"""
    await self._client.write_gatt_char(self._char_uuid, data)
```

## 五、错误处理

### 5.1 捕获特定异常

**只捕获预期的异常**：
```python
# ✅ 正确
async def connect(self) -> bool:
    """连接设备。"""
    try:
        await self._client.connect()
        return True
    except BleakNotFoundError:
        _LOGGER.error("设备未找到")
        return False
    except BleakError as e:
        _LOGGER.error(f"连接失败: {e}")
        return False

# ❌ 错误：捕获所有异常
async def connect(self) -> bool:
    """连接设备。"""
    try:
        await self._client.connect()
        return True
    except Exception:
        return False
```

---

### 5.2 日志记录

**使用 _LOGGER 记录错误**：
```python
import logging

_LOGGER = logging.getLogger(__name__)

async def connect(self) -> bool:
    """连接设备。"""
    try:
        await self._client.connect()
        _LOGGER.info("设备已连接")
        return True
    except BleakNotFoundError:
        _LOGGER.error("设备未找到")
        return False
    except BleakError as e:
        _LOGGER.error(f"连接失败: {e}")
        self._last_error = str(e)
        return False
```

---

### 5.3 错误存储

**记录最后错误供UI显示**：
```python
class BLEDevice:
    def __init__(self):
        self._last_error: str | None = None
        
    async def connect(self) -> bool:
        """连接设备。"""
        try:
            await self._client.connect()
            self._last_error = None  # 清除错误
            return True
        except BleakError as e:
            self._last_error = str(e)  # 保存错误
            _LOGGER.error(f"连接失败: {e}")
            return False
```

## 六、字符串格式化

### 6.1 f-strings（推荐）

**使用 f-strings 进行字符串格式化**：
```python
# ✅ 正确
name = "设备"
battery = 85
message = f"{name} 电量为 {battery}%"

# ❌ 错误：使用 % 格式化
message = "%s 电量为 %d%%" % (name, battery)

message = "{} 电量为 {}%".format(name, battery)
```

```python
    pass
```

## 七、代码注释

### 7.1 文档字符串

**公开方法必须有文档字符串**：
```python
async def read_battery(self) -> int:
    """读取设备电量。
    
    Returns:
        int: 电量百分比（0-100），如果读取失败返回 -1
        
    Raises:
        BleakError: 如果BLE操作失败
    """
    try:
        data = await self._client.read_gatt_char(UUID_BATTERY)
        return data[0]
    except BleakError as e:
        _LOGGER.error(f"读取电量失败: {e}")
        return -1
```

---

### 7.2 行内注释

**使用注释解释"为什么"而非"是什么"**：
```python
# ✅ 正确：解释原因
await asyncio.sleep(0.5)  # 等待设备处理数据

# ❌ 错误：重复代码
await asyncio.sleep(0.5)  # 等待0.5秒

# ✅ 正确：解释复杂逻辑
# 指数退避：每次失败后延迟加倍
delay = min(5 * (2 ** retry_count), 60)
await asyncio.sleep(delay)
```

```python
    @property
    def connected(self):
        pass
```

## 九、性能优化

### 9.1 避免循环中创建Task

**❌ 错误**：
```python
for device in devices:
    hass.async_create_task(device.connect())  # 大量并发Task
```

**✅ 正确**：
```python
tasks = [device.connect() for device in devices]
await asyncio.gather(*tasks)  # 合并执行
```

---

### 9.2 使用缓存

**缓存特征值引用**：
```python
# ✅ 正确
async def _setup_device(self):
    """设置设备。"""
    services = self._client.services
    
    # 缓存特征值
    self._char_battery = services.get_characteristic(UUID_BATTERY)
    self._char_notify = services.get_characteristic(UUID_NOTIFY)
    
# ❌ 错误：每次都查找
async def read_battery(self):
    """读取电量。"""
    services = self._client.services
    char = services.get_characteristic(UUID_BATTERY)  # 重复查找
    data = await char.read_value()
```

## 十一、检查清单

### 提交前检查

- [ ] 所有文件以 `from __future__ import annotations` 开头
- [ ] 所有函数有返回类型注解
- [ ] 使用 PEP 604 语法（`int | None` 而非 `Optional[int]`）
- [ ] 集合类型使用内置泛型（`list[str]` 而非 `List[str]`）
- [ ] 属性有类型注解
- [ ] 异步函数使用 `async def`
- [ ] 回调使用 `@callback` 装饰器
- [ ] 捕获特定异常（如 `BleakNotFoundError`）
- [ ] 使用 `_LOGGER` 记录错误
- [ ] 记录最后错误到 `self._last_error`
- [ ] UUID使用全小写
- [ ] 常量使用 UPPER_SNAKE_CASE
- [ ] 私有成员使用 `_` 前缀
- [ ] 公开方法有文档字符串
- [ ] 使用 f-strings 格式化字符串
