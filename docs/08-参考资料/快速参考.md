# 快速参考

> **常用信息速查卡片**

---

## 📱 UUID 速查（全小写）

| UUID（全小写）                      | 用途           | 操作类型       |
| ----------------------------------- | -------------- | -------------- |
| `0000ffe0-0000-1000-8000-00805f9b34fb` | 扫描过滤       | 只读           |
| `0000ffe1-0000-1000-8000-00805f9b34fb` | 按钮事件通知   | 通知           |
| `0000ffe2-0000-1000-8000-00805f9b34fb` | 断开报警策略   | 写入           |
| `00002a06-0000-1000-8000-00805f9b34fb` | 即时报警       | 写入（无响应） |
| `00002a19-0000-1000-8000-00805f9b34fb` | 电量读取       | 读取           |

---

## 🔄 操作顺序（必须遵守）

```
1. 连接
2. 服务发现
3. 开启通知（ffe1）
4. 读取电量（2a19）
5. 配置策略（ffe2）
6. 准备就绪
```

## 💻 bleak API（>= 0.21.0）

```python
# ❌ 旧 API（错误）
services = await client.get_services()

# ✅ 新 API（正确）
services = client.services  # 属性，不是方法
```

## 📝 按钮事件格式

```
字节0: 事件类型
  - 0x01 = 单击
  - 0x02 = 双击
  - 0x03 = 长按
字节1-6: 保留（0x00）
```

## ⚙️ 配置参数速查

| 参数              | 默认值   | 范围          | 说明           |
| ----------------- | -------- | ------------- | -------------- |
| 电量轮询间隔      | 360分钟  | 5-10080 分钟  | 电量更新频率   |
| RSSI 轮询间隔     | 10分钟   | 1-60 分钟     | 信号强度频率   |
| 维持连接          | 关闭     | 开/关         | 保持常驻连接   |
| 断开报警          | 关闭     | 开/关         | 断开时报警     |

## 🚨 常见问题速查

| 问题              | 可能原因           | 解决方案               |
| ----------------- | ------------------ | ---------------------- |
| 扫描不到设备      | 设备未开机/太远    | 靠近<1米，确认电量     |
| 连接频繁断开      | 信号干扰/电池低    | 更近距离，更换电池     |
| 电量不更新        | 轮询间隔太长       | 缩短轮询间隔           |
| 按钮事件不触发    | 通知未开启         | 检查 ffe1 通知状态     |
| 报警不响          | 2a06 写入方式错误  | 使用 response=False    |
