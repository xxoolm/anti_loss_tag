# 首次连接指南

> **完成设备添加后的首次连接和验证**
> 
**目标读者**：普通用户  
**预计时间**：5分钟  
**难度等级**：⭐ 简单

---

## 一、连接流程概览

```
添加设备
  ↓
自动连接
  ↓
服务发现
  ↓
开启通知（FFE1）
  ↓
读取电量（2A19）
  ↓
配置策略（FFE2）
  ↓
设备就绪
```

---

## 二、首次连接步骤

### 步骤1：确认设备状态

**设备准备**：
- ✅ 设备已开机
- ✅ 设备电量充足（> 20%）
- ✅ 设备在蓝牙适配器范围内（< 5米）
- ✅ 设备未被其他设备连接

**Home Assistant准备**：
- ✅ 蓝牙适配器已启用
- ✅ 集成已安装并重启
- ✅ Config Flow已完成

---

### 步骤2：查看连接状态

1. 进入 **设置** → **设备与服务**
2. 找到 **BLE 防丢标签** 集成
3. 点击进入设备详情
4. 查看以下实体：
   - `binary_sensor.{设备名}_connected`（连接状态）
   - `sensor.{设备名}_battery`（电量）
   - `sensor.{设备名}_rssi`（信号强度）

**预期结果**：
- 连接状态：**on**（已连接）
- 电量：显示百分比（0-100%）
- 信号强度：显示dBm值（如 -65）

---

### 步骤3：验证连接成功

**检查清单**：

| 检查项                | 预期结果                    | 如何检查                                  |
| --------------------- | --------------------------- | ----------------------------------------- |
| 设备连接状态          | on（已连接）                | 查看连接状态二进制传感器                   |
| 电量显示              | 显示百分比                  | 查看电量传感器                             |
| 信号强度              | 显示负数（dBm）             | 查看RSSI传感器                             |
| 设备名称              | 显示您设置的名称            | 设备列表中                                 |
| 实体数量              | 7-9个实体                   | 设备详情页                                 |

**如果连接失败？**
- 查看故障排除指南：[常见问题](../03-故障排除/常见问题.md#连接失败)

---

## 三、设备操作测试

### 测试1：触发报警

测试设备是否能响应报警命令。

**步骤**：
1. 进入 **设置** → **设备与服务** → **BLE 防丢标签**
2. 找到 **button.{设备名}_trigger_alarm** 实体
3. 点击 **执行**
4. 观察设备是否开始报警（响/震/闪）

**预期结果**：
- 设备立即开始报警
- 可以通过再次点击取消报警

**如果报警不响？**
- 检查设备电量
- 确认设备支持即时报警（2a06）
- 查看日志：`设置` → `系统` → `日志`

---

### 测试2：按钮事件

测试设备按钮是否正常工作。

**步骤**：
1. 进入 **设置** → **开发者工具** → **事件**
2. 在 **监听事件** 中输入：`anti_loss_tag_button_event`
3. 按下设备上的按钮（单击/双击/长按）
4. 查看事件列表

**预期结果**：
- 事件类型显示：`单击`、`双击` 或 `长按`
- 事件数据包含：`entity_id`、`event_type`、`raw_data`

**示例事件数据**：
```json
{
  "entity_id": "event.my_keys_button_event",
  "event_type": "单击",
  "raw_data": "01000000000000"
}
```

**如果没有事件？**
- 确认 `maintain_connection` 已开启
- 检查通知是否开启（FFE1）
- 查看日志

---

### 测试3：电量读取

测试电量读取功能。

**步骤**：
1. 记录当前电量值
2. 等待电量轮询间隔（默认360分钟）
3. 或手动触发重新加载

**手动触发电量读取**：
```
设置 → 设备与服务 → BLE 防丢标签
点击"重新加载"按钮
```

**预期结果**：
- 电量值更新
- 如果电量 < 20%，触发低电量提醒（如果配置了自动化）

**如果电量不更新？**
- 检查轮询间隔设置
- 确认设备支持电量读取（2a19）
- 手动触发重新加载

## 四、实体说明

### 创建的实体列表

添加设备后，会自动创建以下实体：

#### 传感器 (Sensor)

| Entity ID                          | Friendly Name         | 说明                    |
| ----------------------------------- | --------------------- | ----------------------- |
| `sensor.{设备名}_battery`           | {设备名} 电量          | 电池电量百分比          |
| `sensor.{设备名}_rssi`             | {设备名} 信号强度      | 蓝牙信号强度（dBm）     |
| `sensor.{设备名}_last_error`       | {设备名} 最后错误      | 最后一次错误信息        |

#### 二进制传感器 (Binary Sensor)

| Entity ID                                  | Friendly Name       | 说明                |
| ------------------------------------------- | ------------------- | ------------------- |
| `binary_sensor.{设备名}_connected`          | {设备名} 已连接      | 设备是否已连接      |
| `binary_sensor.{设备名}_in_range`           | {设备名} 在范围内    | 设备是否在蓝牙范围内 |
| `binary_sensor.{设备名}_far_away`           | {设备名} 远离告警    | 设备信号是否过弱    |
| `binary_sensor.{设备名}_anti_loss_status`   | {设备名} 防丢状态    | 防丢功能是否激活    |

#### 按钮 (Button)

| Entity ID                      | Friendly Name     | 说明           |
| ------------------------------- | ----------------- | -------------- |
| `button.{设备名}_trigger_alarm` | {设备名} 触发报警 | 触发设备报警   |

#### 开关 (Switch)

| Entity ID                             | Friendly Name      | 说明             |
| -------------------------------------- | ------------------ | ---------------- |
| `switch.{设备名}_alarm_on_disconnect`  | {设备名} 断连报警  | 启用/禁用断连报警 |

#### 事件 (Event)

| Entity ID                        | Friendly Name   | 说明             |
| --------------------------------- | --------------- | ---------------- |
| `event.{设备名}_button_event`     | {设备名} 按键    | 按钮事件监听     |

## 五、配置验证

### 验证1：检查配置参数

确认配置是否正确应用：

1. 进入 **设置** → **设备与服务** → **BLE 防丢标签**
2. 点击设备
3. 点击 **配置**
4. 查看所有配置参数：

| 参数            | 默认值 | 您的设置 | 说明         |
| --------------- | ------ | -------- | ------------ |
| 维持连接        | 关闭   |          | 建议关闭     |
| 电量轮询间隔    | 360分钟 |          | 6小时更新一次 |
| RSSI轮询间隔    | 10分钟  |          | 10分钟更新一次 |
| 断开报警        | 关闭   |          | 按需开启     |
| 勿扰时段        | 无     |          | 可选设置     |
| 勿扰Wi-Fi       | 无     |          | 可选设置     |

---

### 验证2：检查日志

查看集成日志，确认无错误：

1. 进入 **设置** → **系统** → **日志**
2. 搜索 `anti_loss_tag`
3. 查看最近5分钟内的日志

**正常日志示例**：
```
INFO:设备已连接: AA:BB:CC:DD:EE:FF
INFO:FFE1 通知已开启
INFO:电量已读取: 85%
INFO:策略已配置: 断开报警已启用
```

**错误日志示例**：
```
ERROR:连接失败: AA:BB:CC:DD:EE:FF
WARNING:设备不支持电量读取
ERROR:开启通知失败
```

如果看到错误，请参考：[故障排除指南](../03-故障排除/常见问题.md)

## 六、性能优化建议

### 建议1：关闭维持连接（推荐）

**原因**：
- 省电：减少设备耗电
- 稳定：避免频繁重连
- 兼容：减少连接冲突

**如何设置**：
```
设置 → 设备与服务 → BLE 防丢标签 → 设备 → 配置
维持连接：关闭 ⛔
```

---

### 建议2：调整轮询间隔

**电量轮询**：
- **日常使用**：360分钟（6小时）或更长
- **测试调试**：10-30分钟
- **低电量设备**：720分钟（12小时）或更长

**RSSI轮询**：
- **日常使用**：10分钟（默认值）
- **距离监控**：5分钟
- **低功耗模式**：15-30分钟

---

### 建议3：配置勿扰时段

避免在休息时间触发告警：

```
设置 → 设备与服务 → BLE 防丢标签 → 设备 → 配置
勿扰时段：22:00-08:00
```

## 七、蓝牙网络拓扑（2025.6+新功能）

### 什么是网络拓扑？

**网络拓扑**显示所有蓝牙设备的连接关系：
- **设备图标**：显示所有已发现的设备
- **连接线**：显示设备与Home Assistant的连接路径
- **代理标识**：显示设备通过哪个代理连接

### 如何查看网络拓扑

**步骤**：
1. 进入 **设置** → **设备与服务**
2. 找到 **蓝牙** 集成
3. 点击 **配置**
4. 在 **网络拓扑** 部分查看：
   - 🟢 绿色 = 已连接设备
   - 🟡 黄色 = 在范围内但未连接
   - 🔴 红色 = 连接失败

### 网络拓扑用途

**1. 诊断连接问题**
- 查看设备是否在范围内
- 确认设备通过哪个代理连接
- 识别信号弱设备

**2. 优化蓝牙布局**
- 调整代理位置
- 添加更多代理
- 避免代理重叠

**3. 验证设备状态**
- 实时查看设备连接状态
- 识别离线设备
- 排查连接失败原因

### 网络拓扑示例

```
Home Assistant
    │
    ├── 🟢 ESP-Proxy-1 (客厅)
    │      ├── 🟢 钥匙扣 (直接连接)
    │      ├── 🟢 钱包 (通过代理)
    │      └── 🟡 车钥匙 (在范围内)
    │
    ├── 🟢 ESP-Proxy-2 (卧室)
    │      ├── 🟢 宠物标签
    │      └── 🔴 旧标签 (连接失败)
    │
    └── 🟢 内置适配器
           └── 🟢 测试设备
```

**版本要求**：
- Home Assistant ≥ 2025.6
- 蓝牙集成已配置

**如果没有看到网络拓扑**：
- 确认Home Assistant版本 ≥ 2025.6
- 等待几秒钟让拓扑加载
- 刷新浏览器页面

## 八、常见问题

### Q1: 为什么连接后立即断开？

**可能原因**：
1. 设备被其他应用连接（如手机App）
2. 蓝牙信号不稳定
3. 设备固件问题

**解决方法**：
1. 关闭手机蓝牙或卸载相关App
2. 将设备靠近蓝牙适配器
3. 重置设备

---

### Q2: 为什么电量显示"未知"？

**可能原因**：
1. 设备不支持电量读取（2a19）
2. 连接不稳定，读取失败
3. 电量轮询间隔太长

**解决方法**：
1. 确认设备规格支持电量读取
2. 检查连接状态
3. 手动触发重新加载

---

### Q3: 为什么按钮事件不触发？

**可能原因**：
1. 维持连接未开启
2. 通知（FFE1）未开启
3. 设备不支持按钮功能

**解决方法**：
1. 开启维持连接
2. 检查日志确认通知已开启
3. 使用事件监听器调试

---

### Q4: 连接数已达上限怎么办？

**症状**：
- 添加新设备时连接失败
- 日志显示"连接槽位不足"

**解决方法**：
1. 关闭部分设备的"维持连接"
2. 使用多个蓝牙适配器
3. 使用ESPHome蓝牙代理扩展范围
