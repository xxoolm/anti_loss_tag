# 安装指南

> **Home Assistant BLE 防丢标签集成 - 快速安装**
> 
> **目标读者**：普通用户  
**预计时间**：10 分钟  
**难度等级**：⭐ 简单

---

## 一、安装前准备

### 1.1 系统要求

- ✅ **Home Assistant 版本**：2024.1.0 或更高
- ✅ **Python 版本**：3.11 或更高
- ✅ **蓝牙适配器**：
  - 内置蓝牙适配器
  - USB 蓝牙适配器（推荐蓝牙 5.0）
  - ESPHome 蓝牙代理（推荐用于扩展范围）

### 1.2 硬件要求

- ✅ **KT6368A 防丢标签**（已充电）
- ✅ **设备固件**：支持 BLE 5.1
- ✅ **设备状态**：可以正常广播

### 1.3 权限准备

确保 Home Assistant 有以下权限：
- ✅ 蓝牙扫描权限
- ✅ 蓝牙连接权限
- ⚠️ **位置权限**（某些系统需要，用于蓝牙扫描）

## 二、安装方法

### 方法1：通过 HACS 安装（推荐）

**优势**：自动更新，管理方便

#### 步骤1：安装 HACS

如果还没有安装 HACS，请先安装：
1. 访问 [HACS 官方文档](https://hacs.xyz/docs/use/configuration/basic/)
2. 按照文档完成 HACS 安装
3. 确保 HACS 已在 Home Assistant 中正常运行

#### 步骤2：搜索并安装本集成

1. 在 Home Assistant 中，进入 **HACS**
2. 点击 **集成**（Integrations）
3. 点击右上角的 **⋮** 菜单
4. 选择 **自定义存储库**
5. 添加自定义仓库：
   - **仓库**：`xxoolm/anti_loss_tag`
   - **类别**：集成
6. 点击 **添加**
7. 在集成列表中找到 **BLE 防丢标签**
8. 点击 **下载**
9. 点击 **下载** 确认安装
10. 等待下载完成

#### 步骤3：重启 Home Assistant

**方式1：通过界面**
1. 进入 **设置** → **系统**
2. 点击 **服务器管理**
3. 点击 **重启**

**方式2：通过终端**
```bash
# 如果是 Home Assistant OS
hassio host restart

# 如果是容器
docker restart home-assistant
```

---

### 方法2：手动安装

**适用场景**：无法使用 HACS，或需要开发版本

#### 步骤1：下载集成

1. 访问 [GitHub 仓库](https://github.com/xxoolm/anti_loss_tag)
2. 点击 **Code** → **Download ZIP**
3. 解压下载的 ZIP 文件

#### 步骤2：复制文件

```bash
# 进入 Home Assistant 配置目录
cd ~/.homeassistant

# 创建 custom_components 目录（如果不存在）
mkdir -p custom_components

# 复制集成文件
cp -r /path/to/downloaded/anti_loss_tag/custom_components/anti_loss_tag \
      custom_components/

# 验证文件结构
ls custom_components/anti_loss_tag/
```

应该看到以下文件：
```
__init__.py
manifest.json
config_flow.py
const.py
device.py
...
```

#### 步骤3：重启 Home Assistant

```bash
# 重启 Home Assistant
hassio host restart
# 或
docker restart home-assistant
```

## 三、配置集成

### 步骤1：添加集成

1. 在 Home Assistant 中，进入 **设置**
2. 点击 **设备与服务**
3. 点击 **+ 添加集成**
4. 搜索 **"BLE 防丢标签"** 或 **"Anti Loss Tag"**
5. 点击选择

### 步骤2：扫描设备

1. 集成会自动开始扫描设备（扫描 5 秒）
2. 扫描列表会显示所有发现的设备
3. 格式：`设备名称 (MAC地址)`

**如果扫描不到设备？**
- ✅ 确认设备已开机
- ✅ 确认设备距离足够近（< 10米）
- ✅ 确认蓝牙适配器正常工作
- ✅ 查看 [故障排除指南](../03-故障排除/常见问题.md)

### 步骤3：选择设备并配置

1. 从列表中选择你的设备
2. 配置以下选项：

#### 基本配置

| 配置项 | 说明 | 默认值 | 推荐值 |
| ------ | ---- | ------ | ------ |
| 设备名称 | 设备的显示名称 | 自动生成 | 易识别的名称 |
| 维持连接 | 是否保持常驻连接 | 关闭 | ⚠️ 建议**关闭** |

#### 高级配置（通常不需要修改）

| 配置项 | 说明 | 默认值 | 范围 |
| ------ | ---- | ------ | ---- |
| 电量轮询间隔 | 电量读取频率 | 360分钟 | 5-10080 分钟 |
| RSSI 轮询间隔 | 信号强度读取频率 | 10分钟 | 1-60 分钟 |
| 断开报警 | 断开连接时是否报警 | 关闭 | 开启/关闭 |
| 勿扰时段 | 勿扰时间窗口 | 无 | 00:00-08:00 |
| 勿扰 Wi-Fi | 连接指定 Wi-Fi 时勿扰 | 无 | 家庭 Wi-Fi 名称 |

3. 配置完成后，点击 **提交**

## 四、验证安装

### 验证1：检查设备状态

1. 进入 **设置** → **设备与服务**
2. 找到 **BLE 防丢标签** 集成
3. 点击进入设备详情
4. 应该看到以下实体：
   - `传感器.{设备名}_电量` - 电量百分比
   - `传感器.{设备名}_信号强度` - RSSI 值
   - `二进制传感器.{设备名}_连接状态` - 是否连接
   - `按钮.{设备名}_触发报警` - 触发报警按钮

### 验证2：测试连接状态

1. 将防丢标签靠近 Home Assistant
2. 观察连接状态传感器：
   - **开**：已连接
   - **关**：未连接
3. 电量传感器应该显示当前电量（0-100%）

### 验证3：测试报警功能

1. 点击 **按钮.{设备名}_触发报警**
2. 防丢标签应该开始报警（响/震/闪）
3. 再次点击按钮取消报警

**如果报警不工作？**
- ✅ 确认设备支持即时报警（2a06）
- ✅ 检查设备电量
- ✅ 查看 [故障排除指南](../03-故障排除/常见问题.md)

## 五、配置自动化（可选）

### 场景1：按钮触发自动化

当按下防丢标签按钮时，执行操作：

```yaml
# configuration.yaml 或通过界面创建
automation:
  - alias: "防丢标签按钮触发"
    trigger:
      - platform: event
        event_type: anti_loss_tag_button_event
        event_data:
          device_id: "your_device_id"
    action:
      - service: notify.notify
        data:
          message: "防丢标签按钮被按下！"
```

### 场景2：断开连接报警

当防丢标签断开连接时，发送通知：

```yaml
automation:
  - alias: "防丢标签断开提醒"
    trigger:
      - platform: state
        entity_id: binary_sensor.防丢标签_连接状态
        to: "off"
    condition:
      - condition: state
        entity_id: input_boolean.启用防丢
        state: "on"
    action:
      - service: notify.notify
        data:
          message: "防丢标签已断开连接！"
```

**更多信息**：查看 [基础自动化](./基础自动化.md)

## 六、常见安装问题

### 问题1：安装后找不到集成

**可能原因**：
- 未重启 Home Assistant
- 文件路径不正确
- manifest.json 格式错误

**解决方案**：
```bash
# 检查文件是否存在
ls ~/.homeassistant/custom_components/anti_loss_tag/

# 检查 manifest.json
cat ~/.homeassistant/custom_components/anti_loss_tag/manifest.json

# 重启 Home Assistant
hassio host restart
```

### 问题2：扫描不到设备

**可能原因**：
- 设备未开机
- 蓝牙适配器未工作
- 设备距离太远

**解决方案**：
1. 确认设备已开机且电量充足
2. 尝试将设备靠近（< 1米）
3. 检查蓝牙适配器：
   ```bash
   # Linux
   hciconfig -a
   
   # 检查 Home Assistant 日志
   # 设置 → 系统 → 日志
   ```

### 问题3：连接后立即断开

**可能原因**：
- 设备被其他设备连接
- 蓝牙适配器驱动问题
- 设备固件问题

**解决方案**：
1. 确保设备只连接到一个设备
2. 尝试重启蓝牙适配器
3. 更新设备固件

## 七、卸载集成

### 通过 HACS 卸载

1. 进入 **HACS**
2. 点击 **集成**
3. 找到 **BLE 防丢标签**
4. 点击右上角的 **⋮** 菜单
5. 选择 **卸载**

### 手动卸载

```bash
# 1. 删除集成文件
rm -rf ~/.homeassistant/custom_components/anti_loss_tag

# 2. 重启 Home Assistant
hassio host restart
```

### 删除配置（可选）

1. 进入 **设置** → **设备与服务**
2. 找到 **BLE 防丢标签**
3. 点击 **删除**
4. 确认删除
